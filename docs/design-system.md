# デザインシステム（配色）

海・シャチ（oruca = Orcinus orca）をイメージした配色。ライト/ダークモード両対応。

## 基本パレット

| 役割 | ライト | ダーク | 用途 |
|---|---|---|---|
| navy（紺） | `#0B2545` | 同左 | 見出し・主要な文字色 |
| blue（青） | `#2E6F9E` | `#5A8FBD` | ボタンなど主要な操作色 |
| lightblue（水色） | `#A8D8E8` | `#6F94A8` | 選択状態・控えめな強調 |
| text（本文文字） | `#1A1A1A` | `#E6EBEF` | 本文テキスト |
| text-sub（補助文字） | `#5A6570` | `#7C93A8` | 補足説明・キャプション |
| bg（画面背景） | `#F2F5F7` | `#050B14` | 画面全体の背景 |
| surface（カード背景） | `#FFFFFF` | `#0E1C30` | カード・モーダルなどの地色 |

## 意味を持たせる色

- **green（海藻の緑）** ライト `#6FA96C` / ダーク `#5C8F63`
  「在席中」を示す状態表示専用。在席確認がoruca の中心機能のため、
  一貫した意味を持たせる（多くのチャット/SNSアプリの「緑＝オンライン」と
  同じ考え方）。

## 装飾用の差し色（意味は固定しない）

- **coral（珊瑚）** ライト `#E37B7B` / ダーク `#B86868`
- **sand（砂）** ライト `#F5CC6E` / ダーク `#B99458`
- **sand-tint（砂色を使ったカード背景）** ライト `#FBF0D9` / ダーク `#7A5C2E`
  （ダークモードでは、アクセシビリティを考慮し、本文文字色とのコントラスト比が
  約5.15:1になるよう明るさを調整済み。WCAGの通常テキスト基準4.5:1以上を満たす）

用途を固定せず、装飾バー・アイコンの色・カード背景の薄い色付けなど、
画面ごとに自由に使ってよい。特定の機能的な意味（警告・エラーなど）が
具体的に必要になった場合は、その時に改めて割り当てを検討する。

## アイコン

- 絵文字（Unicode emoji）はOS・端末によってフォントが異なり見た目が変わる
  ため、アイコン用途では使わない（2026-08-16、US-018の検索/閉じるボタンで
  絵文字を使っていたのを機に方針化）
- アイコンセットは`@expo/vector-icons`の**Ionicons**に統一する（Expo標準・
  iOSネイティブ風のデザイン・種類が豊富なため）
- 基本はアウトライン（線画）スタイル（例：`search-outline`）を使い、選択中・
  アクティブな状態のみ塗りつぶし版（例：`search`）に切り替える

## ダークモードの調整方針

- 背景・差し色ともに単純な自動計算（`color-mix`等）ではなく、実際に見た目を
  確認しながら個別に調整した値を使う（自動計算だと彩度・明度のバランスが
  崩れて濁って見えることがあったため）
- 差し色は、ライトモードよりも彩度・明度をやや落とした「くすみ」バージョンに
  差し替える（ライトモードと同じ鮮やかな色をそのまま暗い背景に載せると、
  浮いて見える・眩しく感じるため）

## プレビュー

実際の見た目は開発中に都度確認・調整する（このMarkdown単体では色は再現されない）。
