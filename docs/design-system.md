# デザインシステム

海・シャチ（oruca = Orcinus orca）をイメージした配色。ライト/ダークモード両対応。
全体のトーンは「可愛い系」ではなく「スタイリッシュ・クリーン」寄り（2026-08-16、
開発者と相談の上決定）。

## フォント

**Noto Sans JP** に統一する（見出し・本文とも同じフォントファミリー）。
明朝体（Zen Old Minchoなど）も比較検討したが、迷いが大きくなったため、まずは
安定してクリーンなNoto Sans JPのみで進める（2026-08-16）。

## タイポグラフィのスケール

| 役割 | サイズ | 太さ |
|---|---|---|
| title（画面タイトル） | 22px | 700 (bold) |
| heading（セクション見出し） | 18px | 700 (bold) |
| body（本文） | 16px | 400 (regular) |
| caption（補足・キャプション） | 13px | 400 (regular)、`text-sub`色と組み合わせる |

## 余白（spacing）のスケール

| 名前 | 値 |
|---|---|
| xs | 4px |
| sm | 8px |
| md | 16px |
| lg | 24px |
| xl | 32px |
| xxl | 48px |

## 角丸（radius）のスケール

ピル型（完全な丸角）ボタンは使わない（2026-08-16、開発者の判断でスタイリッシュ
寄りの控えめな角丸に変更）。

| 名前 | 値 | 用途 |
|---|---|---|
| sm | 6px | 入力欄・タグなど小さい要素 |
| md | 10px | ボタン |
| lg | 16px | カード・モーダル |

## アクセシビリティ

- アイコンのみのボタンには`accessibilityLabel`を必ず付ける
- 文字と背景のコントラスト比はWCAGの通常テキスト基準（4.5:1以上）を満たす
- ノッチ・ホームバー等を避けるセーフエリア対応は、各画面が個別実装せず、
  共通のレイアウトラッパー（`react-native-safe-area-context`）で統一する

| 役割 | ライト | ダーク | 用途 |
|---|---|---|---|
| navy（紺） | `#0B2545` | 同左 | 見出し・主要な文字色 |
| blue（青） | `#2E6F9E` | `#5A8FBD` | ボタンなど主要な操作色 |

## 意味を持たせる色

- **green（海藻の緑）** ライト `#6FA96C` / ダーク `#5C8F63`
  「在席中」を示す状態表示専用。在席確認がoruca の中心機能のため、
  一貫した意味を持たせる（多くのチャット/SNSアプリの「緑＝オンライン」と
  同じ考え方）。

## 装飾用の差し色（意味は固定しない）

- **coral（珊瑚）** ライト `#E37B7B` / ダーク `#B86868`
- **sand（砂）** ライト `#F5CC6E` / ダーク `#B99458`
- **sand-tint（砂色を使ったカード背景）** ライト `#FBF0D9` / ダーク `#7A5C2E`
  （ダークモードでは、アクセシビリティを考慮し、本文文字色とのコントラスト比が
  約5.15:1になるよう明るさを調整済み。WCAGの通常テキスト基準4.5:1以上を満たす）

用途を固定せず、装飾バー・アイコンの色・カード背景の薄い色付けなど、
画面ごとに自由に使ってよい。特定の機能的な意味（警告・エラーなど）が
具体的に必要になった場合は、その時に改めて割り当てを検討する。

## アイコン

- 絵文字（Unicode emoji）はOS・端末によってフォントが異なり見た目が変わる
  ため、アイコン用途では使わない（2026-08-16、US-018の検索/閉じるボタンで
  絵文字を使っていたのを機に方針化）
- アイコンセットは`@expo/vector-icons`の**Ionicons**に統一する（Expo標準・
  iOSネイティブ風のデザイン・種類が豊富なため）
- 基本はアウトライン（線画）スタイル（例：`search-outline`）を使い、選択中・
  アクティブな状態のみ塗りつぶし版（例：`search`）に切り替える

## ダークモードの調整方針

- 背景・差し色ともに単純な自動計算（`color-mix`等）ではなく、実際に見た目を
  確認しながら個別に調整した値を使う（自動計算だと彩度・明度のバランスが
  崩れて濁って見えることがあったため）
- 差し色は、ライトモードよりも彩度・明度をやや落とした「くすみ」バージョンに
  差し替える（ライトモードと同じ鮮やかな色をそのまま暗い背景に載せると、
  浮いて見える・眩しく感じるため）

## プレビュー

実際の見た目は開発中に都度確認・調整する（このMarkdown単体では色は再現されない）。

## ローディング・空データ・エラー表示

- **ローディング**：将来的には「シャチが泳ぐ」「海藻が揺れる」「ヒトデが動く」
  ような、oruca 独自の海のアニメーションを画面ごとに使い分けたい（2026-08-16、
  開発者の意向）。ただし実際のイラスト・アニメーション素材の制作が必要なため、
  現段階では`app/components/LoadingIndicator.tsx`にシンプルな仮実装を用意し、
  将来素材ができた時点でアニメーションを差し替える前提にする
- **空データ**：「まだ何も登録されていません」のような、単なる空白ではなく
  一言添えたメッセージを表示する（`app/components/EmptyState.tsx`）
- **エラー**：エラーコードをそのまま出さず、親しみやすい一言メッセージ＋
  必要なら再試行ボタンを表示する（`app/components/ErrorState.tsx`）
- **操作結果のフィードバック**：成功時はブロックしない**トースト通知**
  （自動で消える）、削除・退会など取り消せない操作の確認は**ネイティブの
  Alert**（ブロックする確認ダイアログ）、と使い分ける

## リスト・アバター・日時表示

- 友達一覧・エリア一覧などは共通の`app/components/ListItem.tsx`を使う
  （行の高さ・余白・区切り線を統一）
- アバター（`USERS.icon_url`）が無い場合は、名前の頭文字を丸背景に表示する
  プレースホルダー（`app/components/Avatar.tsx`）を使う
- 時刻表示は`14:23`のようなコロン区切り（「14時23分」は使わない）
- 在席人数は「3人在席中」の形式で表示する（0人の場合は「在席中の人はいません」）
- どちらも`app/utils/format.ts`の`formatTime`/`formatPresenceCount`を使う
