# 用語集（UI文言の統一）

複数のチャットが並行して画面を実装しているため、同じ概念に違う言葉を
当ててしまわないよう、UI上で使う用語をここで統一する。`docs/oruca_PRD.md`で
実際に使われている頻度の高い用語をベースにしている。

| 用語 | 意味 | 言い換え禁止（使わない表現） |
|---|---|---|
| エリア | 登録された監視対象の場所（`AREAS`） | 場所、スポット、地点 |
| 友達 | OTP等で追加した関係（`FRIENDSHIPS`） | フレンド |
| グループ | 友達経由で拡大するコミュニティ単位（`GROUPS`、将来実装） | サークル、コミュニティ |
| 在席中 / 不在 | エリア内にいる/いない状態（`PRESENCE_LOGS`） | オンライン/オフライン、アクティブ/非アクティブ |
| 登録 | エリアを新規に作る操作 | 追加（エリアには使わない。「追加」は友達・グループへの操作に使う） |
| 紐づけ | エリアと友達の関連付け操作（`FRIEND_AREA_LINKS`） | 連携、共有設定 |
| 承認 | 管理者・ユーザーが申請を認める操作 | 許可、OK |
| 通知 | プッシュ通知全般 | お知らせ、アラート |
| ミュート | 特定の相手からの通知・共有を止める操作 | 非表示、ブロック（ブロックは別機能なので混同しない） |

## 迷った時の判断基準

- `docs/oruca_PRD.md`で実際に使われている単語を優先する
- 新しい概念で用語が無い場合は、このファイルに追記してから実装する
